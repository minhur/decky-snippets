Direct zip for Decky's "Install Plugin from URL"

Always points at the newest release, so this address does not change between versions.

https://github.com/minhur/decky-snippets/releases/latest/download/Snippets.zip

Install in game mode

  1. Quick Access Menu (the ... button), Decky tab, gear icon.
  2. Turn on Developer mode, then in the Developer section choose Install Plugin from URL and enter the zip URL above, or Install Plugin from ZIP File if the zip is already on the Deck.
  3. Open Snippets from the Decky tab and add text. Tap an entry to paste it; the pencil edits or deletes.
